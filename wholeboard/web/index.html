        How to get an API key for Claude, OpenAI or Grok
        
      
          
      Claude (Anthropic)
      
          
        
            
      1. Sign in to the Claude Console. A claude.ai chat subscription does not include API use, which is billed separately.
        2. 
            
      2. Add a payment method or buy credits under Settings → Billing.
        3. 
            
      3. Open Settings → API keys and click Create key. Copy it straight away, because it is shown only once. It starts with sk-ant-.
        4. 
            
      4. Here, choose Claude (Anthropic cloud) as the provider, paste the key and click Save, then Test connection.
        5. 
          
      
          
      Instead of pasting the key, you can set ANTHROPIC_API_KEY before starting WholeBoard. Anthropic's guide
      

          
      OpenAI
      
          
        
            
      1. Sign in to the OpenAI platform and add credits on its billing page.
        2. 
            
      2. Open the API keys page and click Create new secret key. Copy it straight away. It starts with sk-.
        3. 
            
      3. Here, choose OpenAI-compatible as the provider and click the OpenAI quick-setup button.
        4. 
            
      4. Paste the key, click Save, then List models and pick a current GPT model. Click Test connection.
        5. 
          
      
          
      Instead of pasting the key, you can set OPENAI_API_KEY before starting WholeBoard.
      

          
      Grok (xAI)
      
          
        
            
      1. Sign in to the xAI Console and add credits.
        2. 
            
      2. Open its API Keys page and create a key. Copy it straight away. It starts with xai-.
        3. 
            
      3. Here, choose OpenAI-compatible as the provider and click the Grok (xAI) quick-setup button.
        4. 
            
      4. Paste the key, click Save, then List models and pick a Grok model. Click Test connection.
        5. 
          
      
          
      Instead of pasting the key, you can set XAI_API_KEY before starting WholeBoard. xAI's guide
      

          
      Keeping keys safe
      
          
        
            
      • WholeBoard stores keys in ~/.wholeboard/config.json, readable only by your user account. Saved keys are never sent back to the page.
        • 
            
      • Every design run spends credit on your account. Set a monthly spending limit in the provider's console.
        • 
            
      • If you share WholeBoard on your network, everyone who opens it uses your key.
        • 
            
      • If a key leaks, delete it in the provider's console and create a new one.

      Other suppliers
      
      
      Optional. For parts JLCPCB cannot fit (no LCSC number, missing or short of stock) the quote asks Mouser and DigiKey for stock and prices; without keys it links to their search pages. Mouser: a Search API key from mouser.com/api-hub. DigiKey: an app with the Product Information V4 API at developer.digikey.com.
